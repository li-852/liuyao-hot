# 专业易学推演系统

> 一款**离线可用**的易学排盘工具：梅花易数、六爻预测、易学基础常识，一站式完成起卦、排盘与查阅。
> 支持安卓 App 与网页两种方式，**内容更新无需重装**。

---

## ✨ 简介

「专业易学推演系统」是一个纯本地、可离线运行的易学工具，内置历法与六十四卦数据，不依赖服务器即可完整使用。它把常用的三块功能整合在一个应用里：

- **梅花易数**：时间起卦、卦数起卦、物数起卦、声音起卦、字数起卦、以象起卦，一键成卦并排盘。
- **六爻预测**：完整的六爻装卦排盘，含纳支、六亲、六兽、世应、变卦等，辅助断卦。
- **基础内容**：易学百科，涵盖阴阳爻象、八卦五行、干支速查、六神象意、六十四卦、地支比较等，支持关键词搜索。

界面简洁、竖屏适配手机，支持深色模式、主题色、大字模式等个性化设置。

## 📱 安装

### 方式一：安卓 App（推荐）

1. 向维护者获取安装包 **`app.apk`**（或通过群文件 / 网盘下载）。
2. 将 `app.apk` 传到手机，点击安装。
3. 若提示「未知来源」，到 **设置 → 安全 → 允许安装未知来源应用** 后重试。
4. 安装完成后，桌面会出现「易学」图标，点击即可使用。

> App 已内置全部数据，**装好后无需联网也能完整使用**。

### 方式二：网页 / 添加到主屏幕

在浏览器打开维护者提供的网址，菜单中选择「**添加到主屏幕**」，即可获得全屏、可离线的应用体验（需联网一次完成加载）。

## 🧭 使用

打开应用后是主页，四个入口：

1. **梅花易数** — 选择起卦方式（默认时间起卦，跟随当前日期时间），点「计算并生成排盘」即可得到本卦、互卦、变卦。
2. **六爻预测** — 进入排盘界面，逐爻记录或自动装卦，查看纳支、六亲、六兽、世应与变卦。
3. **基础内容** — 查阅易学常识；顶部搜索框可搜「青龙 / 纳支 / 六亲 / 时辰」等关键词，回车会记住你的**搜索历史**，下次进入可一键复用。
4. **系统设置** — 见下节。

顶部日期时间选择器服务于梅花起卦与四值排盘，支持公历/农历切换与「回到今天」。

## ⚙️ 系统设置

设置按四类整理，点击分类标题可展开 / 收起：

- **🎨 外观显示**：主题色（含自定义）、浅色 / 深色模式、大字模式。
- **☯️ 排盘显示**：爻象符号（点记 / 线条）、文字密度（首字简写 / 完整）、盲断视野（隐藏文字仅留爻象）、返回顶部按钮。
- **🚀 启动与数据**：启动默认页、设置导出 / 导入（JSON 备份）。
- **🔄 更新与诊断**：检查更新、历史版本日志、恢复出厂版本、诊断日志。

所有设置**自动保存并即时生效**。

## 🔄 更新（无需重装）

应用支持**热更新**：内容、界面、功能都可在不卸载、不重装的情况下更新。

- 进入 **设置 → 更新与诊断 → 检查更新**；
- 若有新版本，确认后即可自动下载并刷新生效；
- 更新后如遇异常，可点「**恢复出厂版本**」回到内置版本。
- 「**历史版本日志**」列出每个版本的更新说明，随应用内置、**离线也能查看**。

> 更新需要联网；平时使用完全离线。

## ❓ 常见问题

**Q：装了 App 但没网能用吗？**
能。历法与卦库数据已内置，离线可完整起卦、排盘、查阅。仅「检查更新」需要联网。

**Q：点「检查更新」提示"已是最新版本"，但明明有新版本？**
多为更新源缓存所致，稍等几分钟后重试即可；仍不行可反馈维护者。

**Q：更新失败或更新后界面异常？**
点「设置 → 更新与诊断 → 恢复出厂版本」回到内置版本，不影响继续使用。

**Q：桌面图标显示不全 / 被裁？**
属安卓桌面遮罩的正常表现，应用图标已预留安全边距；如仍有问题可反馈。

**Q：怎么把搜索记录或设置换到另一台手机？**
用「设置 → 启动与数据 → 导出设置」生成备份文件，在新设备「导入设置」恢复。

## 🐞 问题反馈

遇到闪退、按钮无反应、更新失败等问题时，请这样收集信息，方便快速定位：

1. 进入 **设置 → 更新与诊断 → 诊断日志**；
2. 点「**复制日志**」（日志已包含版本号、机型与启动/更新/报错记录）；
3. 将内容连同问题描述、复现步骤，发送给维护者。

## 📌 关于本仓库

本仓库 `liuyao-hot` 只存放应用的**热更新分发物**，**不含任何可读源码**：

- `bundle.enc` —— 应用全部热更内容（结构/样式/逻辑/数据）打包后，用 **AES-256-GCM 加密**的密文；App 运行时用内置密钥解密，源码不会以明文形式出现在仓库或网络上。
- `version.json` —— 版本清单，仅含版本号、更新说明与加密包信息。

版本号采用**纯数字构建号**（如 `12`），逐次递增，只增不减。

> 普通用户无需关心本仓库内容，仅需通过 App 内的「检查更新」获取新版本。
